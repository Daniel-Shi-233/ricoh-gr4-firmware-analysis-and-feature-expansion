# Contributing

Contributions to this repository are accepted under Apache License 2.0, as described in section 5 of `LICENSE`.

Before opening a pull request:

- Submit only material you created or have permission to distribute.
- Do not submit camera firmware, extracted system images, brand artwork, camera readbacks, serial numbers, or private user data.
- Mark device-specific findings with the tested camera model and firmware version. Separate observed results from hypotheses.
- For any camera-writing example, include a backup and readback procedure, and clearly identify unverified behavior.

There is no warranty or support commitment for contributed code or documentation. Contributors remain responsible for rights in their contributions.
